# Working instructions

- Read README.md and docs/decisions.md before changing this repository.
- Respect the agreed projects: reliability index, public transport digital twin, disruption intelligence, neighbourhood mobility.
- Current authorisation covers repository setup, concise documentation, and feasibility research. Do not implement an application or collector until the user explicitly gives the green light.
- Ask one unresolved user question at a time. Preserve accepted decisions.
- Distinguish publisher documentation, owner-reported access, empirically inspected data, and hypotheses.
- Never equate predictions with confirmed arrivals, missing records with cancellations, or graph vulnerability with crowding.
- Document meaningful work using purpose, evidence, decision, limitation, and next action; update the journal and decision log where appropriate.
- Keep credentials, account screenshots, raw data, and exports out of Git. Dataset terms and repository licensing are separate.
- Prefer a small justified pilot and evidence-driven architecture. Do not silently commit earlier candidate technologies as final decisions.
